# volcano_fly_educational — Volcano Sky Tour

Educational 3D "fly to the volcanoes" web app modelled on
https://ceddc.ch/arcgisworldskytour/ (ArcGIS Maps SDK for JS SceneView).
Started 2026-09-05 for Alberto Ardid (University of Canterbury) as a teaching
companion to the Kennedy et al. volcano-terminology paper.

**Live:** https://aardid.github.io/volcano-sky-tour/ — GitHub Pages from `main`
of the public repo https://github.com/aardid/volcano-sky-tour. Every push to
`main` redeploys in ~30–60 s (browser cache is 10 min: hard refresh to see changes).

## Product decisions (keep)
- **New Zealand first.** Boots scoped to NZ (23 GVP Holocene volcanoes), opening
  view centred on the North Island; a header button opens the whole world (1,215).
  `FOCUS` constant in `index.html` holds the country and the opening view.
- **No free-flight feature.** Alberto removed it on 2026-09-05 ("I dont want that
  feature"). Navigation is fly-to on click, orbit, and guided tours only. Do not
  add WASD flying, HUD or a Fly tab back.
- Tabs are Tours / Explore / Learn. NZ tours come first in `tours.js`.
- Live **GeoNet Volcanic Alert Levels** are shown on NZ cards (GVP number →
  GeoNet id map `GEONET_IDS`).

## Files
- `index.html` — the whole app, single file, no build step. ArcGIS SDK 4.34 via
  AMD `require` from js.arcgis.com. Basemap `satellite`, ground `world-elevation`,
  OSM 3D buildings scene layer (item `ca0470dbbddb4db28bad74ed39949e25`). No API key.
- `tours.js` — curated tours: GVP numbers + teaching note + optional camera
  overrides (`dist`, `alt`, `bearing`, `tilt`, `orbit`). Curator-editable.
- `build_data.py` → `data/volcanoes.js` (`window.VOLC`, ~2 MB) from the BK repo
  CSVs (`../000_papers_abs_ppts/BK_paper_2026`). Re-run after `build_catalogue.py`.
- `README.md` — user-facing docs, URL options (`#vn=`, `#vn=N&tour`, `?q=low|high`, `?instant`).
  `#vn=N&tour` (`startTourAt`, `body.focus`) is the deep link used by the BK
  `webapp/index.html` popup button "Take a 3D tour" (opens this app in a new tab):
  legend + side panel hidden, no tour playback, the tab is about that one volcano
  (Alberto, 2026-09-06). Tabs in the header still reopen the panel.

## Conventions
- REF_YEAR 2026; thresholds erupting 0.252 yr / high 500 / moderate 12,000 /
  dormant 2.5e6 — identical to the BK paper figures and the BK `webapp/`.
  Tier colours also identical. Keep them in sync.
- Volcano markers: client-side `FeatureLayer`; filters (tier, landform, country
  scope, search) are a `definitionExpression`.
- Camera framing: `defaultView()` — calderas and volcanic fields are viewed from
  further away than cones; per-stop overrides live in `tours.js`.
- GVP photos need `referrerpolicy="no-referrer"` (volcano.si.edu returns 403 with a referrer).
- GeoNet API needs header `Accept: application/vnd.geo+json;version=2` (version=1 returns 400).

## Related work

## Environment / gotchas
- Windows 11, PowerShell 5.1 + Git Bash; Python 3.13 (pandas). Project lives on a
  UNC share (`\\file\Usersa$\...`).
- Git: global config is unwritable (HOME on P:). Use `git -c safe.directory=*`
  and the repo-local identity (Alberto Ardid <aardids@gmail.com>). Push
  authenticates through Git Credential Manager; set `GCM_INTERACTIVE=never`.
  No `gh` installed (MSI needs admin); the GitHub REST API with the GCM token works.
- Bash heredocs on the UNC path choke on apostrophes: use the Write tool or Python
  for prose-heavy files. Node cannot `require()` from the UNC path: copy to the
  scratchpad for `node --check`.
- Headless smoke test: copy to scratchpad, `python -m http.server` on 127.0.0.1,
  one Chrome at a time with `--headless=new --use-angle=swiftshader
  --enable-unsafe-swiftshader --disable-extensions --user-data-dir=<tmp>
  --virtual-time-budget=60000-90000 --screenshot=...`, URL with `?q=low&instant`.
  Screenshots can still catch the loading/fade state; that is a timing artefact.
